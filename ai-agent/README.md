# AI Agent — ব্যক্তিগত Android সহকারী

এটি বিদ্যমান Phone Manager থেকে আলাদা Gradle প্রকল্প (`ai-agent/`)। Android 8.0 বা নতুন সংস্করণে ব্যক্তিগত sideload-এর জন্য; Play Store প্রকাশের জন্য নয়। স্ক্রিনের Accessibility tree ও আপনার নির্দেশ Gemini-তে পাঠিয়ে সর্বোচ্চ ১৫ ধাপ চালায়। ছবি বা স্ক্রিনশট পাঠায় না।

## জরুরি নিরাপত্তা ও গোপনীয়তা

- কথোপকথনে আগে প্রকাশিত API key **অবিলম্বে revoke/delete করে নতুন key তৈরি করুন**। পুরোনো কী ব্যবহার করবেন না।
- GitHub Secret কোডে প্রকাশিত না হলেও **বিল্ডের APK-র ভিতরে key থাকে**। APK বা Actions artifact যাঁরা পান তাঁরা key বের করতে পারেন। পাবলিক রিপোজিটরিতে artifact প্রকাশ করার ঝুঁকি বুঝুন; শেয়ার করবেন না, সম্ভব হলে private repository ব্যবহার করুন, key-তে সীমা ও billing নিয়ন্ত্রণ রাখুন।
- স্ক্রিনের লেখা, ব্যক্তিগত তথ্য ও নির্দেশ Google-এ পাঠানো হয়। [Google-এর মূল্যতালিকা](https://ai.google.dev/gemini-api/docs/pricing) অনুযায়ী free tier-এর ডেটা পণ্য উন্নয়নে ব্যবহৃত হতে পারে। গোপন তথ্যের স্ক্রিনে ব্যবহার করবেন না।
- তালিকাভুক্ত ছয়টি নির্দিষ্ট package এবং Android যে field-কে password বলে চিহ্নিত করে সেগুলোতে কাজ বন্ধ হয়। তালিকা **সব ব্যাংকিং অ্যাপকে আটকায় না**; package ID ভুল বা পরিবর্তিত হতে পারে, এবং সব গোপন তথ্য password হিসেবে চিহ্নিত থাকে না। অন্যান্য window বা অ্যাপের লুকানো বিষয়ও সম্পূর্ণ শনাক্ত নাও হতে পারে। ফোনটি নজরে রাখুন; অপ্রত্যাশিত কাজ হলে ‘বন্ধ করো’ চাপুন।
- Accessibility ও overlay অত্যন্ত শক্তিশালী অনুমতি। শুধুমাত্র নিজের ও বিশ্বস্ত ডিভাইসে ব্যবহার করুন। মডেলের উত্তর ভুল হতে পারে; অর্থ লেনদেন, ক্রয় বা সংবেদনশীল কাজের জন্য ব্যবহার করবেন না।

## মোবাইলে GitHub Secret ও APK

১. Google AI Studio-তে নতুন Gemini API key তৈরি করুন। পুরোনো প্রকাশিত key বাতিল করুন।
২. GitHub repository → **Settings → Secrets and variables → Actions → New repository secret**। নাম `GEMINI_API_KEY`, মানে নতুন key দিন। এটি কখনও ফাইল বা চ্যাটে লিখবেন না।
৩. এই branch-এর পরিবর্তন main-এ আনুন। main-এ `ai-agent/` পরিবর্তনের push হলে workflow স্বয়ংক্রিয় চলে। অথবা workflow ফাইলটি default branch-এ আসার পর **Actions → AI Agent APK → Run workflow** থেকে পছন্দের branch বেছে ম্যানুয়ালি চালান। Branch-এ চালাতে প্রথমে branch push করতে হবে।
৪. সফল run → **Artifacts → AIAgent-debug** → ZIP ডাউনলোড, extract করে `app-debug.apk` ইনস্টল করুন। প্রয়োজনে Android-এ সেই ডাউনলোড অ্যাপের জন্য unknown apps অনুমতি দিন। Artifact ৭ দিন রাখা হয়।
৫. Debug APK GitHub runner-এর অস্থায়ী signing key দিয়ে সই হয়; পরের বিল্ডে key আলাদা হলে আগের অ্যাপ uninstall করে নতুন APK ইনস্টল করতে হতে পারে।

## ফোনে চালানো

১. AI Agent খুলে **ওভারলে পারমিশন দিন**, তারপর **অ্যাক্সেসিবিলিটি চালু করুন** চাপুন এবং সেটিংসে `AI Agent` খুঁজে সক্রিয় করুন। Android 13+ এ নোটিফিকেশন অনুমতি দিন।
২. **ভাসমান বাটন চালু করুন** চাপুন। ভাসমান বাটন টেনে সরানো যায়। ট্যাপ করে নির্দেশ লিখে **শুরু করো** চাপুন। প্যানেল আবার খুললে অবস্থা দেখা ও **বন্ধ করো** দিয়ে বাতিল করা যায়। অ্যাপের মূল স্ক্রিনে ভাসমান বাটন সম্পূর্ণ বন্ধ করার বাটন আছে।
৩. টাইপ করার আগে এজেন্টকে লেখার ঘর নির্বাচন করতে হয়। Android-এর battery optimization বা নির্মাতার background restriction সার্ভিস বন্ধ করতে পারে; আবার অ্যাপ খুলে চালু করুন।

## বিল্ড ও মডেল

লোকাল বিল্ডে Java 17 এবং Android SDK 35 দরকার। `local.properties.example` দেখে `ai-agent/local.properties` তৈরি করে `GEMINI_API_KEY` দিন; ফাইলটি Git-এ উপেক্ষিত। ঐচ্ছিক `GEMINI_MODEL` দিয়ে মডেল বদলানো যায়; ডিফল্ট `gemini-3.8-flash`। Google-এর বর্তমান মূল্যতালিকায় এর free tier আছে, তবে প্রাপ্যতা, কোটা, অঞ্চল ও মূল্য পরিবর্তিত হতে পারে। পুরোনো `gemini-2.0-flash` বন্ধ হয়েছে।

```
cd ai-agent
./gradlew testDebugUnitTest assembleDebug
```

এখানে সংকলিত কী APK-তে দৃশ্যমান থাকে। `org.json` Android-এ আগে থেকেই আছে; সংঘর্ষ এড়াতে আলাদা লাইব্রেরিটি শুধু JVM unit test-এ ব্যবহৃত। API অনুরোধ ব্যর্থ হলে একবার তিন সেকেন্ড পরে পুনরায় চেষ্টা হয়।
